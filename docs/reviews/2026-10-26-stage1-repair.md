# Diagnostic and frame pipeline repair

The learner approved implementation in audit order and explicitly deferred further physical tests. This first stage changes diagnostics and the production input/geometry boundary, not gesture geometry or performance policy.

The schema3 numeric recorder starts continuous trials immediately, so an all-no-hand attempt still leaves evidence. It separates detected hand from stale result, records each eligibility gate, captures bitmap/inference/roundtrip/delivery and actual cut durations, and keeps full-trial timing histograms independent of compressed sample rows. Current rows, fresh active-hand rows and lifecycle/transition events are bounded separately. Trial identity, start/end/stop cause and recognized/hit counts are explicit. Unknown timings are not zero. Export returns a deep snapshot and leaves the trial running; a separate stop control closes it.

The new GesturePipeline is the actual frame -> gate -> classifier -> geometry callback path used by the page. The component no longer repeats a different hidden version of that path. It records hidden/unfocused/camera/mouse/modal/pre-resume/invalid-viewport/stale causes independently and uses normalized aiming coordinates. Blur, lost pointer capture and released mouse buttons clear pointer cutting; viewport changes cancel old input. Optional camera/tracker/clock factories support a transparent synthetic-input integration test without accessing the webcam.
