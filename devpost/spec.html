HairFit · Technical Spec · draft

从两张图到一段掉落的头发

本规格把已批准的 PRD 转成可以逐步实现的本地网页应用。

01 上传个人照片 + 理想发型
02 生成蒙太奇等待状态
03 预览单张换发大图
04 剪发拖动、掉发、重置

How This Works

浏览器负责页面和 3D 场景；本地代理负责保护 API 密钥并调用阿里云生图接口。3D 使用可控的风格化头部和独立发束，验证剪发体验，不重建用户本人。

组件

  • App Shell and Screen Router：切换上传、生成、结果、3D。
  • UploadPanel：两张图片、缩略图和生成按钮。
  • GenerationMontage：循环等待视觉。
  • ImageGenerationProxy：调用阿里云并记录用量。
  • ResultView：大图和三个动作。
  • HaircutScene：发束命中、变短、掉落、重置。

数据流

浏览器文件 → Session Store → 本地代理 → Alibaba Image API
                         ↓              ↓
                    结果大图 ← 响应解析 ← 用量日志

运行方式

npm install
npm run dev

打开 Vite 输出的本地地址，依次上传两图、生成、进入 3D、拖动头发、展示掉落、点击重置。

文件结构

server/       本地代理、API 调用、用量记录
src/components 上传、等待、结果、3D
src/state/     会话数据
src/lib/       浏览器 API、图片校验、文案
devpost/      比赛规划文档

简化决策

  • 风格化可编辑头部代替个人 3D 重建。
  • 本地会话代替账号和数据库。
  • 鼠标拖动优先于手势追踪。
  • 本地原创或授权蒙太奇代替实时素材流。

外部服务

阿里云 OpenAI 兼容图像接口：/api/v1/services/aigc/multimodal-generation/generation。密钥只在 .env，每次请求记录模型、token、缓存、耗时和成功状态；缺失字段写 unknown。
