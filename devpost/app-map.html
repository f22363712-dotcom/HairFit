HAIRFIT / APP ARCHITECTURE MAP

HairFit 应用全景架构图

从双图上传、阿里云百炼多模态换发代理，到 3D 面部对齐投影与三档渐进式沙龙试剪工作台的完整数据流与模块映射。

核心用户旅程与数据流 (Core Journey & Data Flow)

1. 双图上传 (Upload)

用户上传或一键加载personalImage与hairstyleImage，经 FileReader 转为 DataURL 存入SessionStore。

2. 百炼代理生成 (Proxy)

前端调用POST /api/generate-preview，Node 服务转发至阿里云百炼qwen-image-3.0-pro并返回合成大图。

3. 预览与恢复 (Result)

展示换发大图与原图对照，自动持久化至localStorage，支持重新生成、更换照片或进入 3D。

4. 3D 投射试剪 (3D Studio)

将用户面部对齐投射至 3D 头模，使用精细点剪/牙剪打薄/快速平剪渐进修剪 8,050 根发丝并观察碎发落盘。

状态与路由核心 State & Router

  • src/main.js：单页四屏路由器（upload / generating / result / 3d），管理 3D 场景teardown()生命周期。
  • src/state/session-store.js：集中维护图片 DataURL、请求状态、五区发长百分比hairSections与本地存储同步。

前端视图组件 UI Components

  • src/components/upload-panel.js：双图上传卡片、一键示例填入与直接进入 3D 快捷入口。
  • src/components/generation-montage.js：生成等待期的脉冲呼吸发光球（Orb）动效。
  • src/components/result-view.js：单张大图预览、原图缩略图浮层与三大动作按钮。

3D 试剪工作台 Three.js WebGL

  • src/components/haircut-scene.js：C2 连续人台雕塑、3D 正面人脸对齐投影 Shader、8,050 根双瓣各向异性丝缎发丝、三档渐进式浮点剪刀与零 GC 碎发物理池。

后端安全代理 Node Server

  • server/index.js：本地静态服务与/api/generate-preview、/api/health接口路由。
  • server/image-generation.js：封装阿里云 DashScope 多模态图像生成调用与脱敏日志。
